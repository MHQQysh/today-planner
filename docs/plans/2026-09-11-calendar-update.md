# 日历与 Tasks 界面更新

根据用户截图与明确要求执行：左侧无需时间的 Tasks，右侧 Google Calendar 风格时间网格。电脑默认周视图，手机单日。点击或鼠标拖选创建时间段，点事件编辑/完成/删除；任务不随所选日期变化。

保留旧版 plans 数据结构及本机存储键。新增 tasks 独立表和存储键，沿用用户隔离及修改版本检查。导出和显式导入包含两个集合。

验证：6 项单元测试通过；1440px / 390px 浏览器测试覆盖任务新增完成删除、事件点击新增编辑完成删除、日期切换、刷新持久化、导出、无横向溢出，桌面拖选也通过。真实云端仍等待建表、登录配置与 GitHub 发布。
