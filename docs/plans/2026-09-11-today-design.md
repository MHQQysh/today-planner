# 今日规划设计

用户已同意：中文个人每日时间轴，手机电脑共享，GitHub Pages 网站与 Supabase 免费数据库。
首页包括日期导航、今日目标统计、当前安排、按时间排序的计划列表。新增和编辑采用原生时间选择器，支持分类、备注、完成与删除。空白初始状态不混入示例数据。
未配置云端时本机保存。配置后 GitHub OAuth 登录，以用户 ID 隔离数据。写入成功后更新列表，失败保留编辑表单；每 15 秒及窗口重新聚焦读取云端。编辑使用版本条件避免静默覆盖另一设备修改。云端配置仅公开 URL 和 publishable/anon key，权限由数据库 RLS 强制。
本地记录可导出 JSON；登录后显式导入本机记录。响应式卡片布局，键盘可操作，移动端触控按钮至少 40px。
验证：时间验证、跨日日期计算、统计、移动和桌面新增编辑完成删除及刷新持久化；云端实际联调依赖用户项目。
